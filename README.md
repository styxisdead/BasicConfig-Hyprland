# BasicConfig-Hyprland
A basic config for Hyprland. Still under construction.


# Hello!! thank you so much for taking interest in my project.

This is a very barebones Hyprland config, featuring only the necessities for the look and feel!

Hyprglass plugin IS included in this config, so remember to run "hyprpm enable hyprglass". Edit the preset as you please!

All packages are included in the install. I personally don't use hypridle or hyprlogout, I do it through the terminal. Eventually, for a public release, I will add it. For now, this is just my personal config.

Thanks for visiting!
